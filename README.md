# teacher-curriculum

ملف مناهج الرياضيات (من 1 ابتدائي لـ 3 ثانوي) اللي برنامج «دفتر المُعلّمة» بيسحبه من زرار «سحب آخر نسخة من الإنترنت».

الرابط اللي البرنامج بيقرأ منه:

```
https://raw.githubusercontent.com/ibrahim219w/teacher-curriculum/main/curriculum.json
```

## شكل الملف

- `version`: اسم الإصدار، وبيظهر في البرنامج.
- `grades.<الصف>.terms."1"` و `"2"`: قائمة الوحدات، وكل وحدة فيها `title` و `lessons`.
- `fullYear: true`: معناها إن الصف ليه منهج واحد للسنة كلها، زي تالتة ثانوي.

رموز الصفوف: `p1`–`p6` للابتدائي، و`m1`–`m3` للإعدادي، و`s1`–`s3` للثانوي.
